Sidebar ideas for Canopy

These are sketches, not a new theme yet. They borrow from Herdr’s agent cards, sessionx’s flat switcher, and file navigators like yazi and k9s. The current tree can stay. The gain is less chrome and a clearer status.

Herdr. Workspace, then tab, then agent. Status is a pill or card, not a long word on the tree row. Provider icons matter more than tmux indices.
sessionx. A centered list plus a preview, search first. Good as a jump surface, a poor persistent sidebar. Canopy already has the tree for that.
yazi / k9s. Indent instead of pipes. Selection is a full row. Key hints live in a footer, so the top line is the place, not a tab strip.
