Canopy · appearance study

The last column should be the mark.

Quiet is already the default, and it is the right idea: a session, window, and pane tree, with idle shells dimmed and agent state reduced to a glyph. Next to the other sidebars people leave open, it still reads as busier than the job requires. The path, the branch, and the status glyph take turns being the last thing on the line, and brand color paints icons that are not asking for anything.

Reserve a blank column for ! and ▷, and draw icons in the same dim ink as a path. Keep the question in normal ink, under its pane. Those three changes use the layout Canopy already has. A pinned “someone is waiting” shelf is worth adding only when that question can scroll off a long tree.

What the other sidebars spend a narrow pane on

Each of these is a reduction of the published UI, at about the width of a docked sidebar. Canopy is the only one whose job is the whole tmux workspace and the agents inside it. The useful borrowings are alignment, a single status color, and age. The dashboards themselves belong to tools that do not have to show the editor.

Zellij’s session switcher is a short modal list, name and tab count, which is the same family as Canopy’s popup. sesh and tmux-sessionx are wide fzf windows with a preview beside the list. Canopy’s popup mode already has that room. The appearance problem is the dock that stays open at 42 columns while you edit. tmux-pane-tree stays a compact tree with badges; quiet is already that shape, with more in the edge than the edge can hold.

Sketches on the same workspace

Same sessions, same selection on OpenCode, same active pane in Neovim. Each sketch changes one thing. The hairline before the mark is drawn so the empty cells show up on this page; in the terminal that column is blank.

The inspector is a card that doesn’t line up

The drawer already has the right fields: state, trust, directory, git, place, then the request. They are printed as a stack of dim lines, so the card looks like a log. A label column is the same information with a straight edge. No new chrome.

Leave these with the tools that need them

  • A permanent row of filter chips. ◆1 ▷2 is that row, already fitted to the header. Chips earn a line in a sidebar that contains only agents.
  • A tile for every pane. Neovim and a shell are not tasks. Two lines is the right height for an agent that has a question, and one line is the right height for everything else. The folders appearance already has the boxed header for people who want lazygit’s chrome.
  • Emoji, and a braille spinner beside the working mark. The age is the calmer clock. The working mark already moves, and it already stops while you are typing in the sidebar.
  • A different color per directory. That study is next to this one. Painting the scaffolding makes the mark harder to find, which is the problem this page is trying to shrink.
