Header and footer system

State above. Actions below.

The recommended header replaces the permanent tab strip with the current view, active subset, and global summary. The footer changes with the selected row or active operation.

Top bar = orientationView and filter on the left. Counts or an urgent mode on the right. Selection details stay in the row and preview so the header does not jump.
Footer = immediate actionsPrimary action first, then agent-specific actions, navigation, and finally view/help shortcuts. Items disappear from the right as space narrows.
