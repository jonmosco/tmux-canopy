Actual runtime output · not another mockup

Three states. One inspector.

These text and ANSI captures came from real Canopy sidebars in attached clients on private tmux servers. Agent executables and lifecycle events were synthetic fixtures. No live user sessions were accessed.

Native frame, spacing, text, row limits, and blank space are preserved from the capture. ANSI colors are mapped to this page’s palette; browser font metrics are not a pixel-perfect photograph of your terminal. The frame is drawn by fzf, not by CSS inside the captured output.
